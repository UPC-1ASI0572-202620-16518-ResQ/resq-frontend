# ResQ device photography

Place the team's own photographs of the purchased MVP hardware in this directory. The Devices UI automatically shows a neutral “Hardware photo pending” fallback when an image is not available or cannot be loaded.

| Filename               | Required photograph                     |
| ---------------------- | --------------------------------------- |
| `resq-mvp-node.webp`   | Complete assembled ResQ Safety Node MVP |
| `esp32-devkit-v1.webp` | Purchased 30-pin ESP32 DevKit V1        |
| `mq2.webp`             | Purchased MQ-2 gas/smoke sensor module  |
| `oled-ssd1306.webp`    | Purchased SSD1306 0.96-inch I2C OLED    |
| `active-buzzer.webp`   | Purchased 5 V active buzzer             |
| `led-red.webp`         | Purchased red 5 mm LED                  |
| `led-green.webp`       | Purchased green 5 mm LED                |

## Photography and replacement guidance

- Use original photos of the hardware acquired by SecurityBear; do not use store, marketplace, manufacturer, or stock images.
- Export as WebP at 800 × 800 px or larger, preferably with a square aspect ratio.
- Use a white or very light gray background and a clear front or three-quarter view.
- Keep the entire component visible with comfortable padding around it.
- Preserve the filenames above exactly. Replacing or adding a file requires no code change.
- Avoid embedding labels or measurements into the image; the accessible name and technical context are supplied by the interface.
